# KAZINO 🎰

ブラウザで遊べるWeb版と、ターミナルで遊べるPython版があるカジノゲーム集です。

## Web版

ラスベガスのカジノに入るような流れで遊べます。

1. **入口**: ネオン看板の前で「入場する」か「会員登録」を選ぶ
2. **会員カウンター**: ニックネーム・メールアドレス・パスワードで登録すると、会員カードが発行されてチップ 1000 枚がもらえる
3. **入場**: 扉が開いてカジノフロアへ
4. **カジノフロア**: ブラックジャック・スロット・ルーレット・ビデオポーカーのテーブルと、チップ持ちランキング（ハイローラーズ）

ほかに、1日1回のボーナス（+500枚）、所持チップで上がる会員ランク（ブロンズ → シルバー 2,000枚 → ゴールド 5,000枚 → プラチナ 20,000枚）、プレイ回数・勝率の記録があります。

### 保存先

- **Firebase の設定あり**: アカウントとチップがオンラインに保存され、どの端末からでも同じアカウントで遊べます。ランキングも全員分が表示されます。
- **設定なし（オフラインモード）**: アカウントはそのブラウザの中にだけ保存されます。設定しなくてもすぐ遊べます。

### Firebase の設定手順

1. [Firebase コンソール](https://console.firebase.google.com/) で「プロジェクトを追加」し、プロジェクトを作る（Google アナリティクスはオフで大丈夫です）
2. 左メニューの「構築」→「Authentication」→「始める」→「ログイン方法」で **メール / パスワード** を有効にする
3. 「構築」→「Firestore Database」→「データベースを作成」。ロケーションは `asia-northeast1`（東京）、**本番環境モード** で作成する
4. Firestore の「ルール」タブを開き、このリポジトリの `firestore.rules` の中身を貼り付けて「公開」
5. 「プロジェクトの設定」（歯車）→「マイアプリ」で **ウェブ（`</>`）** を追加。表示された `firebaseConfig` の値を `docs/js/firebase-config.js` に貼り付ける
6. GitHub Pages で公開する場合は、「Authentication」→「設定」→「承認済みドメイン」に `haruki083.github.io` を追加する

`firebase-config.js` の値は公開しても問題ない設定値です。データは `firestore.rules` で「自分のデータしか書き換えられない」ように守っています。ただしチップの計算はブラウザ側で行っているので、詳しい人ならチップの数をごまかせます（本物のお金を扱わないゲームなので、この作りにしています）。

### GitHub Pages で公開する

リポジトリの Settings → Pages で「Deploy from a branch」を選び、`main` ブランチの `/docs` フォルダを指定します。

### ファイル

```
docs/
  index.html             画面（入口・会員カウンター・フロア・各ゲーム）
  css/style.css          デザイン
  js/firebase-config.js  Firebase の設定値（ここに貼り付ける）
  js/backend.js          アカウントの保存（Firebase / オフライン）
  js/app.js              入口 → 会員カウンター → フロアの流れ、会員カード、ボーナス、ランキング
  js/games.js            4つのゲーム
firestore.rules          Firestore のセキュリティルール
```

## ターミナル版の遊び方

Python 3.10 以上が必要です。

```bash
python main.py
```

メニューから番号でゲームを選びます。最初はチップ 1000 枚から始まり、所持チップは `save_data.json` に自動で保存されます。チップがなくなったら 1000 枚にリセットされます。

## ゲーム

| ゲーム | ルール |
| --- | --- |
| ブラックジャック | 21 に近い方が勝ち。ヒット・スタンド・ダブルダウンができます。ディーラーは 17 以上で止まり、ブラックジャックは 1.5 倍の配当です。 |
| スロット | 3 つの絵柄がそろうと配当。👑👑👑 は 200 倍、🍒 が 2 つでも 2 倍です。 |
| ルーレット | ヨーロピアン式（0〜36）。数字ひとつ（36 倍）、赤/黒・偶数/奇数・前半/後半（2 倍）、ダース（3 倍）に賭けられます。 |
| ビデオポーカー | ジャックス・オア・ベター。5 枚から残すカードを選んで 1 回交換し、J 以上のワンペアから配当があります。 |

倍率はすべて「賭け金込みの払い戻し」です（例: 10 枚賭けて 2 倍なら 20 枚戻る＝ 10 枚の勝ち）。
