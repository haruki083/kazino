# KAZINO 🎰

ターミナルで遊べるカジノゲーム集です。Python だけで動き、追加のライブラリは要りません。

## 遊び方

Python 3.10 以上が必要です。

```bash
python main.py
```

メニューから番号でゲームを選びます。最初はチップ 1000 枚から始まり、所持チップは `save_data.json` に自動で保存されます。チップがなくなったら 1000 枚にリセットされます。

## ゲーム

| ゲーム | ルール |
| --- | --- |
| ブラックジャック | 21 に近い方が勝ち。ヒット・スタンド・ダブルダウンができます。ディーラーは 17 以上で止まり、ブラックジャックは 1.5 倍の配当です。 |
| スロット | 3 つの絵柄がそろうと配当。👑👑👑 は 200 倍、🍒 が 2 つでも 2 倍です。 |
| ルーレット | ヨーロピアン式（0〜36）。数字ひとつ（36 倍）、赤/黒・偶数/奇数・前半/後半（2 倍）、ダース（3 倍）に賭けられます。 |
| ビデオポーカー | ジャックス・オア・ベター。5 枚から残すカードを選んで 1 回交換し、J 以上のワンペアから配当があります。 |

倍率はすべて「賭け金込みの払い戻し」です（例: 10 枚賭けて 2 倍なら 20 枚戻る＝ 10 枚の勝ち）。

## フォルダ構成

```
main.py            メニュー（起動ファイル）
casino/
  wallet.py        チップの管理とセーブ
  ui.py            入力・表示の共通処理
  cards.py         トランプと山札
  blackjack.py     ブラックジャック
  slots.py         スロット
  roulette.py      ルーレット
  poker.py         ビデオポーカー
tests/             テスト
```
